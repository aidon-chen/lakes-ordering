## 发版步骤（控制台手动上传）

1. 打开 **微信云托管控制台** → 环境 `prod-d6gd6a2twe27f592a` → 服务 **`bar-mvp`**
2. 点 **「新建版本」** → 选择 **「本地上传代码包」** → 上传本 zip
3. 等待云端构建（多模块 Maven，约 **3–5 分钟**）；构建日志出现 `BUILD SUCCESS` 即通过
4. 确认部署配置（**沿用上一版即可，不要改**）：
   - 监听端口 **9200**（必须与 `server.port` 一致）
   - 健康检查：初始延迟 **180 秒**，HTTP 探 `/<context-path>/actuator/health`
   - 环境变量：`SPRING_PROFILES_ACTIVE` + `MYSQL_ADDRESS` / `MYSQL_USERNAME` / `MYSQL_PASSWORD`（**缺一个就会"假健康"或连不上库**）
5. 构建完成后 **发布/部署** 该版本
6. 验证：
   - 浏览器打开 `https://bar-mvp-315579-12-1488393615.sh.run.tcloudbase.com/siam-server/actuator/health` → 应为 `UP`
   - 小程序里走「商城 → 加购 → 结算 → 去支付」→ 应能下单成功（不再「系统异常」）

## 为什么不用 wxcloud CLI

本工程实测（技能 `wxcloudrun-deploy-troubleshoot` 有记录）：**CLI 直发不可用** —— `env:list` 持续失败（服务端 `ret:-3`），且扫码登录拿到的 token **只 console.log、未落盘也未接入部署命令**。**控制台手动上传是唯一可用路径。**
